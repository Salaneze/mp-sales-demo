# Продажи с маркетплейса — в таблицу и в Telegram

Скрипт забирает из кабинета продавца заказы и остатки по складам, ведёт
Google-таблицу (или Excel) и пишет в Telegram о важном: новый заказ, отмена,
товар заканчивается, итоги дня.

Работает через **официальный API продавца** по токену из личного кабинета.
Витрину маркетплейса не парсит: у Wildberries она закрыта собственной
защитой (ответ 498, JS-проверка), и парсер витрины ломается от каждого
обновления сайта. API продавца стабилен и отдаёт ровно ваши цифры.

Для демонстрации есть тестовый магазин (`--demo`): правдоподобные заказы,
остатки тают по мере продаж. Таблица и уведомления — настоящие.

## Что внутри

- **Заказы без дублей.** WB присылает заказ повторно, когда он меняется
  (например, отменён). Ключ заказа — `srid`, поэтому повтор обновляет строку,
  а отмена приходит отдельным уведомлением.
- **Честные остатки.** В отчёте WB рядом со складами лежат сводные строки
  «В пути до получателей», «Всего находится на складах». Их сумма со складами
  завышает остаток в разы — скрипт их отбрасывает.
- **«Заканчивается» один раз.** Сообщение приходит в момент, когда остаток
  опустился до порога, а не каждый час, пока товар на нуле.
- **Лимиты WB.** Отчёты — 1 запрос в минуту; на ответ 429 скрипт ждёт и
  повторяет. Окно запроса с нахлёстом 40 минут: WB обновляет заказы раз в
  30 минут, а дубли всё равно отсекаются.
- **Первый запуск молчит** — подтягивает историю за 3 дня в таблицу, но не
  шлёт её пачкой «новых заказов».
- **Деньги — `Decimal`**, суммы за день без копеечных ошибок float.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env

python -m mpsales --demo                       # тестовый магазин
python -m mpsales --demo --now 2026-10-20T12:00  # перемотать магазин вперёд
python -m mpsales                              # ваш кабинет WB (WB_TOKEN)
python -m mpsales --every 1h                   # по расписанию
python -m mpsales --summary                    # итоги дня в Telegram
```

Результат — `data/sales.xlsx`: листы «Заказы», «Остатки», «По дням».

## Токен WB

Личный кабинет → Настройки → Доступ к API → токен с категориями
**Статистика** и **Аналитика**, режим **только чтение**. С таким токеном
скрипт физически не может изменить цены или карточки.

## Настройки (`.env`)

| Переменная | Что | По умолчанию |
|---|---|---|
| `WB_TOKEN` | токен API продавца | — |
| `LOW_STOCK` | порог «заканчивается», шт. по всем складам | 5 |
| `TG_TOKEN`, `TG_CHAT_ID` | бот и чат для уведомлений | выключено |
| `GSHEET_ID`, `GSHEET_CREDENTIALS` | таблица Google и JSON сервисного аккаунта | выключено |

## Расписание на сервере

```
0 * * * *  cd /opt/mpsales && .venv/bin/python -m mpsales >> mpsales.log 2>&1
0 21 * * * cd /opt/mpsales && .venv/bin/python -m mpsales --summary
```
